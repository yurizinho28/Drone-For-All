# 🚁 Drone For All
 
> Sistema de monitoramento inteligente de alagamentos urbanos via drone para a ETEC Alberto Santos Dumont.
 
---
 
## 📖 Sobre o Projeto
 
O **Drone For All** é um drone de reconhecimento de área que analisa as ruas das cidades e identifica quais estão alagadas, com o objetivo de informar aos alunos da **ETEC Alberto Santos Dumont** se haverá aula ou não.
 
A solução visa proporcionar mais segurança e praticidade para os estudantes, eliminando a incerteza em dias de chuva intensa ao fornecer informações em tempo real sobre as condições das vias ao redor da escola.
 
---
 
## ✨ Funcionalidades
 
- 🌊 Identificação de vias alagadas
- 🔔 Notificação sobre a situação das aulas para os alunos
- 🗺️ Visualização das áreas monitoradas em mapa
